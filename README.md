NutriTrack is a user-friendly website designed to encourage healthy eating habits and make food tracking easier. It allows users to create profiles based on their food preferences, explore personalised meal suggestions and record their daily food intake through a food diary. The website also provides a Nutrition Overview to display basic nutritional information and a Water Tracker to help users monitor their water intake. It is built using HTML, CSS and JavaScript, with Local Storage to save user information and the Open Food Facts API to retrieve additional food-related information. NutriTrack aims to combine technology and nutrition to help people make more informed food choices and develop healthier eating habits.
